## How it works:
### The final game is a top-down arcade space shooter built in Godot 4 where the player controls a spaceship restricted within screen boundaries, shooting lasers at falling meteors to survive and score points. Meteors spawn randomly from the top of the viewport and travel downwards, triggering collisions that destroy them when struck by a laser or damage the player ship upon collision. While a floating User Interface (UI) overlay tracks and updates the player's current score and remaining lives. The entire gameplay loop takes place across a single infinite scrolling or static space background level, resetting the main level scene whenever the player loses lives.
